# Revision of Digital Design

Revisiting Digital Design fundamentals through practical circuit design, simulation, and verification using Proteus.

## 🎯 Objectives

- Strengthen fundamental Digital Design concepts.
- Apply theoretical knowledge through practical circuit implementation.
- Simulate digital circuits using Proteus.
- Verify circuit behaviour against truth tables and expected results.
- Document implementations for future reference and continued learning.

## 📚 Topics to Be Covered

Based on *Digital Design* by M. Morris Mano:

1. Digital Systems and Binary Numbers
2. Boolean Algebra and Logic Gates
3. Gate-Level Minimization
4. Combinational Logic
5. Synchronous Sequential Logic
6. Registers and Counters
7. Memory and Programmable Logic
8. Design at the Register Transfer Level
9. Laboratory Experiments with Standard ICs and FPGAs

## 🛠️ Tools & Learning Resources

- **Circuit Design & Simulation:** Proteus
- **Primary Textbook:** M. Morris Mano — *Digital Design*
- **Video Lectures:** Neso Academy

## 🔬 Implementation Approach

Each circuit implementation may include:

- Objective and design requirements
- Relevant logic expressions and truth tables
- Proteus project files
- Simulation screenshots
- Verification against expected results
- Brief observations and references

## 📂 Repository Structure

Implementations will be organized by topic, with relevant documentation and simulation files for each circuit.

## 📈 Progress

This repository will evolve as the topics are revised, circuits are implemented, and simulation results are verified.
